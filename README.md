# HitachiBagusAssessment 🚀

[![Kotlin](https://img.shields.io/badge/Kotlin-2.0.21-blue.svg)](https://kotlinlang.org/)
[![Android SDK](https://img.shields.io/badge/Android%20SDK-36-brightgreen.svg)](https://developer.android.com/)
[![License](https://img.shields.io/badge/License-MIT-lightgrey.svg)](LICENSE)

A clean architecture Android app to **search GitHub users** and view their details using **MVVM**, **Hilt**, **Retrofit**, and **Glide**.

---

## Features ✨

- Search GitHub users by username
- View user details: avatar, followers, following
- Loading, success, and error UI states
- Clean architecture with `domain`, `data`, and `ui` layers
- Dependency injection with **Hilt**
- Jetpack components: ViewModel, LiveData, Navigation, ViewBinding
